# Notice and supplied assets

This repository contains adapted educational material supplied in `41068_ignition_bringup_v1.zip`, including the Husky and Parrot visual meshes, forest texture, bridge configuration patterns and parts of the original URDF/Gazebo setup.

The supplied archive did not contain a licence file. Before making this repository public, the team must confirm the redistribution terms for those assets with the teaching staff or original provider. New EmberTrace source code may be relicensed later only after that check is complete.

The original world referenced several Gazebo Fuel models by URL. EmberTrace replaces those references with simple local primitive models so the main forest world can start without downloading Fuel assets.
